# 🎲 真心话大冒险 - AstrBot 插件

一款群聊派对游戏插件。玩家加入游戏后通过 Roll 点决定命运，机器人随机指定玩家完成真心话或大冒险事件，完成后再进入下一轮。

> 💡 所有指令均以 `/td` 子指令形式使用（如 `/td join`、`/td start`），避免与其他插件冲突。

## ✨ 功能特性

- 🎮 完整的游戏流程：加入 → 开始 → Roll 点 → 指定/补足 → 处理事件 → 完成 → 下一轮
- 🎯 动态目标人数：4人抽2人，每+2人多+1人（6人→3人，8人→4人...）
- 💬 内置真心话题库和大冒险任务库，支持自定义
- ⚖️ 可配置真心话/大冒险出现概率
- 🎲 **全新指定机制**：所有人 Roll 完后，从 6 种算法随机选一种选出"指定权获得者"，由其指定 1 名玩家，系统按相同算法补足剩余名额
- 🎚️ **可自定义指定事件类型与内容**：指定时可选择用 `1`=真心话 / `2`=大冒险，并可附加自定义事件内容（例：`/td 指定 @玩家 1 说说最近最尴尬的事`）
- 🔒 管理员踢人机制（解决 AFK 卡死问题）
- ⏱️ 可配置每轮冷却时间
- 👥 可配置最少/最多参与人数（默认最少4人）
- 📋 玩家列表、Roll 结果查看
- ⏭️ 支持跳过当前事件
- 🛑 优雅结束游戏
- 👢 管理员踢人（解决 AFK 卡死问题）
- 💾 数据持久化（重启后自动恢复游戏状态）

## 📦 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 目录下，然后在 WebUI 插件管理处重载插件即可。

## 🎮 游戏流程

```
1. /td join   —— 玩家加入游戏
2. /td start  —— 开始游戏（至少需要 4 人）
3. /td roll   —— 所有玩家 Roll 点（1-100，所有人完成后自动进入下一阶段）
4. /td go     —— 查看当前轮状态 / 触发指定流程（显示指定权获得者提示）
5. /td 指定   —— 指定权获得者指定 1 名玩家进行事件
6. 系统自动按相同算法补足剩余名额，每人独立随机真心话/大冒险
7. /td done   —— 被选中的玩家完成事件后确认（需所有人完成才进入下一轮）
8. /td go     —— 开始下一轮...
   ...
N. /td stop   —— 结束游戏
```

## 📐 动态人数规则

| 参与人数 | 事件目标人数 |
|----------|--------------|
| 4人 | 2人 |
| 6人 | 3人 |
| 8人 | 4人 |
| 10人 | 5人 |
| ... | 每+2人→+1人 |

## ⚙️ 配置项

在 AstrBot WebUI 的插件配置页面可以修改以下选项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `min_players` | int | 4 | 最少参与人数 |
| `max_players` | int | 50 | 最大参与人数 |
| `roll_min` | int | 1 | Roll 点最小值 |
| `roll_max` | int | 100 | Roll 点最大值 |
| `truth_questions` | text | 内置题库 | 真心话题库（每行一个） |
| `dare_tasks` | text | 内置题库 | 大冒险任务列表（每行一个） |
| `truth_weight` | int | 50 | 真心话权重（0-100，50 表示各 50%） |
| `round_cooldown` | int | 0 | 每轮冷却时间（秒，0 为无冷却） |
| `round_timeout` | int | 0 | 单轮超时时间（秒，0 为不启用；超时自动跳过防卡死） |
| `admin_ids` | list | [] | 管理员 QQ 号兜底列表（群角色获取失败时生效，可执行踢人/清除指定） |

## 🎯 游戏机制说明

### 新指定机制（核心变更）

1. **Roll 点阶段**：所有玩家发送 `/td roll`，所有人完成后自动提示进入指定阶段
2. **随机算法选择**：系统从 6 种算法中随机选择一种：
   - 点数最大 / 点数最小
   - 单数点数最大 / 单数点数最小
   - 双数点数最大 / 双数点数最小
3. **选出指定权获得者**：用选中的算法从所有玩家中选出 1 名"指定权获得者"（不公开身份）
4. **玩家指定**：指定权获得者使用 `/td 指定 @玩家 [1|2] [内容]` 指定 1 名玩家进行事件（类型与内容可省略，省略时随机）
5. **系统补足**：系统用**相同算法**从剩余玩家中补足名额，直到达到动态目标人数
6. **独立事件分配**：每个被选中的玩家**独立**随机获得真心话或大冒险（可全真心话、全大冒险、或混合，玩家指定且指定了类型时使用指定类型）
7. **完成确认**：所有被选中玩家需各自发送 `/td done` 确认完成，全部完成后才进入下一轮

### 指定事件类型与内容

在 `/td 指定` 时可附带数字类型与自定义内容，类型用 **`1`** 代表真心话、**`2`** 代表大冒险；省略类型或内容时随机抽取。

| 用法 | 说明 |
|------|------|
| `/td 指定 @玩家` | 随机类型 + 随机内容 |
| `/td 指定 @玩家 1` | 指定为真心话，内容随机 |
| `/td 指定 @玩家 2` | 指定为大冒险，内容随机 |
| `/td 指定 @玩家 1 说说最近最尴尬的事` | 指定为真心话，内容自定义 |
| `/td 指定 @玩家 2 喝掉一罐可乐` | 指定为大冒险，内容自定义 |
| `/td 指定 玩家名 1 内容` | 不 @ 时用名字指定（同群名匹配） |

> 仅此时输入数字 1/2 有效；旧的 `真心话`/`大冒险` 关键字已不再支持。

### 指定权获得者判定

- 只有被随机选中的指定权获得者可以使用 `/td 指定`
- 普通玩家和管理员均无法使用（除非被选中为指定权获得者）
- 指定仅限 1 名玩家，不可指定自己

### 自定义题库

在配置中编辑 `truth_questions` 和 `dare_tasks`，每行一个条目。系统会从题库中随机抽取。
