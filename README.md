# 🎲 真心话大冒险 - AstrBot 插件

一款群聊派对游戏插件。玩家加入游戏后通过 Roll 点决定命运，机器人随机指定玩家完成真心话或大冒险事件，完成后再进入下一轮。

> 💡 所有指令均以 `td_` 开头，避免与其他插件冲突。

## ✨ 功能特性

- 🎮 完整的游戏流程：加入 → 开始 → Roll 点 → 处理事件 → 完成 → 下一轮
- 🎯 动态目标人数：4人抽2人，每+2人多+1人（6人→3人，8人→4人...）
- 💬 内置真心话题库和大冒险任务库，支持自定义
- ⚖️ 可配置真心话/大冒险出现概率
- 🔒 管理员踢人机制（解决 AFK 卡死问题）
- ⏱️ 可配置每轮冷却时间
- 👥 可配置最少/最多参与人数（默认最少4人）
- 📋 玩家列表、Roll 结果查看
- ⏭️ 支持跳过当前事件
- 🛑 优雅结束游戏
- 👢 管理员踢人（解决 AFK 卡死问题）

## 📦 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 目录下，然后在 WebUI 插件管理处重载插件即可。

## 🎮 游戏流程

```
1. /td_join   —— 玩家加入游戏
2. /td_start  —— 开始游戏（至少需要 4 人）
3. /td_roll   —— 所有玩家 Roll 点（1-100）
4. /td_go     —— 机器人处理事件，随机指定玩家
5. /td_done   —— 被选中的玩家完成事件后确认
6. /td_go     —— 开始下一轮...
   ...
N. /td_stop   —— 结束游戏
```

| 指令 | 别名 | 说明 |
|------|------|------|
| `/td_join` | `/td加入` `/tdjoin` | 加入游戏 |
| `/td_leave` | `/td退出` `/tdleave` | 退出游戏（游戏未开始时） |

| `/td_result` | `/td结果` `/tdresult` | 查看所有玩家 Roll 结果 |
| `/td_go` | `/tdgo` `/td下一轮` | 处理事件，指定玩家 |
| `/td_指定` | `/td指定` `/tddesignate` | 管理员手动指定本轮目标（优先级高于 Roll 点） |

## 📐 动态人数规则

| 参与人数 | 事件目标人数 |
|----------|--------------|
| 4人 | 2人 |
| 6人 | 3人 |
| 8人 | 4人 |
| 10人 | 5人 |
| ... | 每+2人→+1人 |

## ⚙️ 配置项

在 AstrBot WebUI 的插件配置页面可以修改以下选项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `min_players` | int | 4 | 最少参与人数 |
| `max_players` | int | 50 | 最大参与人数 |
| `roll_min` | int | 1 | Roll 点最小值 |
| `roll_max` | int | 100 | Roll 点最大值 |
| `truth_questions` | text | 内置题库 | 真心话题库（每行一个） |
| `dare_tasks` | text | 内置题库 | 大冒险任务列表（每行一个） |
| `truth_weight` | int | 50 | 真心话权重（0-100，50 表示各 50%） |
| `round_cooldown` | int | 0 | 每轮冷却时间（秒，0 为无冷却） |

## 🎯 游戏机制说明

### Roll 点与目标选择

1. 所有玩家 Roll 点后，发送 `/td_go` 触发事件处理
2. 机器人找出 Roll 点最低的玩家作为优先目标
3. 根据玩家总数动态计算目标人数（4人→2人，每+2人→+1人）
4. 事件类型（真心话/大冒险）按配置权重随机决定
5. 管理员可通过 `/td_指定 @玩家1 @玩家2` 手动指定本轮目标，优先级高于 Roll 点

### 自定义题库

在配置中编辑 `truth_questions` 和 `dare_tasks`，每行一个条目。系统会从题库中随机抽取。
